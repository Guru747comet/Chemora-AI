What is extracted?

The backend extracts selectable text and provides rule-based keyword hints for review. It does not independently validate disease or target claims.

After extraction, correct the disease name and target list, save them, and continue to molecular analysis.

Scanned PDFs without selectable text will be rejected with an OCR-unavailable message.
